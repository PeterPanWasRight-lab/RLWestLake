# 同策略策略梯度算法总结

## 1. 同策略随机策略梯度算法 (Stochastic Policy Gradient, SPG)

### 1.1 核心公式
策略梯度定理表达式：
$$
\nabla_\theta J(\theta) = \mathbb{E}_{S \sim \eta, A \sim \pi_\theta} \left[ \nabla_\theta \log \pi_\theta(A|S) \cdot Q_\pi(S, A) \right]
$$
其中：
- $\pi_\theta(a|s)$：参数化的随机策略函数  
- $Q_\pi(s,a)$：动作值函数  
- $\eta(s)$：状态的平稳分布[2,10](@ref)

### 1.2 算法特性
| 特性 | 说明 |
|------|------|
| **同策略机制** | 行为策略与目标策略相同（$A \sim \pi_\theta$），需当前策略生成样本[9](@ref) |
| **探索来源** | 策略本身的随机性（如高斯分布的方差）[9,11](@ref) |
| **动作空间** | 兼容离散和连续空间（通过Softmax/高斯分布参数化）[10](@ref) |
| **梯度计算** | 依赖策略概率密度 $\nabla_\theta \log \pi(a|s)$，需动作采样[2](@ref) |
| **方差特性** | 估计方差较高，需配合基线函数或Critic网络[10](@ref) |

### 1.3 典型算法
- **REINFORCE**：蒙特卡洛策略梯度（无Critic）[12](@ref)  
- **A2C/A3C**：Actor-Critic架构，引入基线减少方差[10](@ref)  
- **PPO**：带约束的策略优化，保证更新稳定性[10](@ref)

## 2. 同策略确定性策略梯度算法 (Deterministic Policy Gradient, DPG)

### 2.1 核心公式
确定性策略梯度表达式：
$$
\nabla_\theta J(\theta) = \mathbb{E}_{S \sim \rho^\mu} \left[ \nabla_\theta \mu(S) \cdot \nabla_a Q^\mu(S, a) \big|_{a=\mu(S)} \right]
$$
其中：
- $\mu_\theta(s)$：确定性策略函数  
- $\nabla_a Q^\mu(s,a)$：动作值函数对动作的梯度[10](@ref)  

### 2.2 算法特性
| 特性 | 说明 |
|------|------|
| **同策略实现** | 需在确定性输出 $\mu(s)$ 上添加探索噪声（如OU过程）[9](@ref) |
| **动作空间** | 仅适用于连续动作空间（$\nabla_a Q$ 在离散空间无定义）[10](@ref) |
| **梯度计算** | 通过链式法则直接优化动作值，无需动作概率分布[10](@ref) |
| **效率优势** | 比SPG更高效处理高维连续控制问题[8](@ref) |

### 2.3 典型算法
- **DDPG**：深度确定性策略梯度（经验回放+目标网络）[8](@ref)  
- **TD3**：改进DDPG，解决值函数高估问题[8](@ref)

## 3. 关键对比
| **特性** | **随机策略梯度 (SPG)** | **确定性策略梯度 (DPG)** |
|----------|------------------------|--------------------------|
| **策略输出** | 动作分布 $\pi(a\|s)$ [10](@ref) | 动作值 $\mu(s)$ [10](@ref) |
| **动作空间兼容性** | 离散/连续 [10](@ref) | 仅连续 [10](@ref) |
| **梯度计算** | $\nabla_\theta \log \pi \cdot Q$ [2](@ref) | $\nabla_\theta \mu \cdot \nabla_a Q$ [10](@ref) |
| **探索机制** | 策略内生随机性 [9](@ref) | 外部添加噪声 [9](@ref) |
| **样本效率** | 较低（On-policy）[9](@ref) | 较高（Off-policy兼容）[8](@ref) |
| **收敛速度** | 较慢但稳定 [15](@ref) | 较快需精细调参 [15](@ref) |

## 4. 结论
1. **SPG优势**：  
   - 通用性强（支持离散/连续动作空间）  
   - 探索更自然（策略内生随机性）[11](@ref)  

2. **DPG优势**：  
   - 计算效率高（避免动作积分）  
   - 适合高维连续控制（如机器人控制）[8](@ref)  

3. **选择建议**：  
   - 需探索的离散任务：优先选SPG（如PPO）  
   - 高效连续控制任务：优先选DPG（如TD3）[8,10](@ref)
